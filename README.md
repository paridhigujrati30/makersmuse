# MakersMuse 🌸

MakersMuse is a product booking website built using HTML, CSS, and JavaScript. It includes product pages, booking functionality, a shopping cart, and a feedback system.

## ✨ Features

- **Product Display:** Browse products through a dedicated products page.
- **Booking System:** Select an item and enter customer details and delivery days.
- **Shopping Cart:** Add items to the cart, view the total price, remove individual items, and clear the cart.
- **Feedback System:** Submit feedback and view previously submitted feedback.
- **Feedback Export:** Export saved feedback to a `.txt` file.
- **Local Storage:** Store cart items and feedback in the browser using `localStorage`.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 📂 Project Pages

- `index.html` — Main page
- `products.html` — Product page
- `booking.html` — Booking page
- `cart.html` — Shopping cart
- `feedback.html` — Feedback page
- `contact.html` — Contact page

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Navigate through the available pages to explore the website.
